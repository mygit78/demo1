第二步：杜邦分析

ROE = 净利率 × 资产周转率 × 权益乘数
= (净利润/营业收入) × (营业收入/平均总资产) × (平均总资产/平均净资产)
拆解：盈利能力 + 运营效率 + 杠杆水平

第三步：偿债能力

流动比率 = 流动资产 / 流动负债
速动比率 = (流动资产 - 存货) / 流动负债
现金比率 = 货币资金 / 流动负债
资产负债率 = 总负债 / 总资产
利息保障倍数 = EBIT / 利息支出

第四步：运营能力

应收账款周转天数 = 365 / (营业收入/平均应收账款)
存货周转天数 = 365 / (营业成本/平均存货)
应付账款周转天数 = 365 / (营业成本/平均应付账款)
现金周转天数 = 应收天数 + 存货天数 - 应付天数

第五步：盈利能力

毛利率 = (营业收入-营业成本)/营业收入
净利率 = 净利润/营业收入
期间费用率 = (销售+管理+研发+财务费用)/营业收入
ROA = 净利润/平均总资产

第六步：现金流质量

经营现金流/净利润比率 (>1 盈利质量高)
自由现金流 = 经营现金流 - 资本开支
现金流组合模式判断：经营±/投资±/筹资±

第七步：EVA 经济增加值

EVA = NOPAT - 资本成本
NOPAT = 营业利润 × (1 - 有效税率)
资本成本 = 投入资本 × WACC
投入资本 = 所有者权益 + 有息负债 - 在建工程
WACC 假设 = 8%

第八步：综合诊断

汇总预警信号：
• 经营现金流是否持续为负
• 资产负债率是否过高 (>80%)
• 应收账款周转是否恶化
• 毛利率是否持续下滑
• EVA是否为负

综合诊断

核心结论

海尔生物医疗(688139) 2025年度财务表现呈现"增收不增利"的特征。营业收入同比微增1.96%至23.29亿元，但归母净利润同比大幅下滑31.61%至2.51亿元。主要原因系销售费用大幅增长23.76%及研发费用持续高投入（占营收13.88%）所致。

公司资产负债率仅20.17%，偿债能力优秀；经营现金流为正（2.68亿），但盈利质量指标（经营现金流/净利润 = 1.05）表明盈利质量较好。EVA为-1.16 亿，已转负，存在价值毁损风险。

2026年Q1延续下滑趋势，营收同比-5.36%，归母净利润同比-27.93%，经营现金流大幅缩减至1,168万（同比-68.63%），需持续关注。

建议关注

1. 销售费用高增长：2025年销售费用同比增长23.76%（从2.90亿增至3.59亿），远超收入增速1.96%，销售费用率从12.71%升至15.43%。需评估市场推广投入产出效率。

2. 利润持续下滑：归母净利润从2024年的3.67亿降至2025年的2.51亿（-31.61%），Q1延续下滑（-27.93%）。若趋势延续，需关注盈利能力恢复能力。

3. 应收账款快速增长：应收账款从2024年末3.24亿增至2025年末4.04亿（+24.9%），再增至2026Q1末5.05亿（+25%），增速远超收入增速，回款压力加大。

4. 偿债能力优秀：资产负债率仅20.17%，流动比率2.45，速动比率2.13，偿债能力良好。

5. 研发投入持续高：研发费用率保持13.88%高位（2024年13.41%），有利于长期竞争力，但短期内加大利润压力。
